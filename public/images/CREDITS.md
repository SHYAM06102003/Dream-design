## Before launch

1. Replace every file with real photography of your own projects.
2. Delete the rows above for images you no longer use.
3. If any placeholder image is kept, keep its row — the licence requires the
   credit.
4. The same attribution data lives in `src/data/images.ts` (the `credit` field on
   each image), which is the single place to update a path or a credit.
